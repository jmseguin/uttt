# Agents

This project uses Antigravity, a powerful agentic AI coding assistant.

## Agent Guidelines
- **Expert .NET Core developer**: Follow C# naming conventions and clean code principles.
- **Cross-Platform Focus**: Ensure all code runs on Windows, macOS, and Linux.
- **Game Engine Specialization**: Implement robust win detection and efficient AI algorithms.
- **Testing**: Ensure all code has 100% unit test coverage.
- **UI**: Flexible, fluid UI that operates the same on all platforms.
